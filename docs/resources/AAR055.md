When a document uses the `x-payload-references` extension to point a payload to its Avro schemas, every reference must be complete and well formed, so that the schemas can be located in the registry and in the repository.

Wherever `x-payload-references` appears, in AsyncAPI 2.x and 3.x alike, it must be an array of objects, and each object must contain three non-empty fields:

- `subject`: the subject name in the schema registry (letters, digits, `:`, `_`, `.` and `-`).
- `ref`: the URL of the `.avsc` file in the repository (`http`, `https`, `svn`, `svn+ssh` or `file` scheme).
- `referenceName`: the fully qualified Avro type name, a lowercase dot-separated namespace followed by a capitalized type name (for example `org.madrid.core.payload.alumnos.Ciudadano`).

An extension that is not an array, an item that is not an object, and each missing, empty or malformed field are reported.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud.beca:
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
          properties:
            applicant:
              type: object
        x-payload-references:
          - subject: beca.cmd.alumnos.solicitud.beca-value
            ref: https://svn.quality.es/schemas/avro/Ciudadano.json # Noncompliant {{AAR055: Item at index 0 in 'x-payload-references' has an invalid 'ref' value; it must be an SVN URL that points to a .avsc file.}}
            referenceName: org.madrid.core.payload.alumnos.Ciudadano
          - subject: beca.cmd.alumnos.solicitud.beca-direccion # Noncompliant {{AAR055: Item at index 1 in 'x-payload-references' is missing the required non-empty field 'referenceName'.}}
            ref: https://svn.quality.es/schemas/avro/Direccion.avsc
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud.beca:
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
          properties:
            applicant:
              type: object
        x-payload-references:
          - subject: beca.cmd.alumnos.solicitud.beca-value
            ref: https://svn.quality.es/schemas/avro/Ciudadano.avsc
            referenceName: org.madrid.core.payload.alumnos.Ciudadano
          - subject: beca.cmd.alumnos.solicitud.beca-direccion
            ref: https://svn.quality.es/schemas/avro/Direccion.avsc
            referenceName: org.madrid.core.payload.alumnos.Direccion
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  scholarshipRequested:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      scholarshipRequested:
        payload:
          type: object
          properties:
            applicant:
              type: object
        x-payload-references:
          - subject: '' # Noncompliant {{AAR055: Item at index 0 in 'x-payload-references' is missing the required non-empty field 'subject'.}}
            ref: https://svn.quality.es/schemas/avro/Ciudadano.avsc
            referenceName: Ciudadano # Noncompliant {{AAR055: Item at index 0 in 'x-payload-references' has an invalid 'referenceName' value; it must be a fully qualified Avro type name (lowercase namespace and capitalized type).}}
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  scholarshipRequested:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      scholarshipRequested:
        payload:
          type: object
          properties:
            applicant:
              type: object
        x-payload-references:
          - subject: beca.cmd.alumnos.solicitud.beca-value
            ref: https://svn.quality.es/schemas/avro/Ciudadano.avsc
            referenceName: org.madrid.core.payload.alumnos.Ciudadano
```
