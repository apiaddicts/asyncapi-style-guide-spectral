The second segment of every channel (topic) name is its classification and must be one of the allowed values, so that consumers can tell at a glance what kind of events a topic carries.

By default the allowed classifications are `cdc` (Change Data Capture), `cmd` (a command that triggers a domain modification) and `sys` (an internal system topic, not intended for public consumption). The comparison is case-sensitive, and a name without a second segment (no dot) or with an empty one is also reported. In AsyncAPI 2.x the name is the channel key. In AsyncAPI 3.x it is the channel `address`, or the channel key when the channel has no `address` field; a channel whose `address` is `null` is not checked.

Parameters
----------

- `validValues` — list of the classifications allowed in the second segment, as an array of strings. Default: `["cdc", "cmd", "sys"]`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.evt.alumnos.solicitud.beca: # Noncompliant {{AAR054: Channel name 'beca.evt.alumnos.solicitud.beca' has an invalid classification segment 'evt'. The second segment must be one of: cdc, cmd, sys.}}
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
  beca.CDC.alumnos.direccion.beca: # Noncompliant {{AAR054: Channel name 'beca.CDC.alumnos.direccion.beca' has an invalid classification segment 'CDC'. The second segment must be one of: cdc, cmd, sys.}}
    subscribe:
      operationId: onAddressChanged
      message:
        name: AddressChanged
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud.beca:
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
  beca.cdc.alumnos.direccion.beca:
    subscribe:
      operationId: onAddressChanged
      message:
        name: AddressChanged
        payload:
          type: object
```
