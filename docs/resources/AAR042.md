Every message should declare a `messageId`, a unique identifier that lets tools and consumers refer to the message unambiguously.

The rule checks the messages defined in `components.messages` and, in AsyncAPI 2.x, the `message` of every `publish` and `subscribe` operation of the channels. A message without a `messageId`, or with an empty one, is reported. A message referenced with `$ref` is reported once, where it is defined. In AsyncAPI 3.x only the messages under `components.messages` are checked.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      operationId: publishOrderCreated
      message:
        $ref: '#/components/messages/OrderCreated'
  orders.cancelled:
    subscribe:
      operationId: onOrderCancelled
      message: # Noncompliant {{AAR042: Message should have a 'messageId' field for unique identification.}}
        name: OrderCancelled
        payload:
          type: object
          properties:
            orderId:
              type: string
components:
  messages:
    OrderCreated: # Noncompliant {{AAR042: Message should have a 'messageId' field for unique identification.}}
      name: OrderCreated
      payload:
        type: object
        properties:
          orderId:
            type: string
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      operationId: publishOrderCreated
      message:
        $ref: '#/components/messages/OrderCreated'
  orders.cancelled:
    subscribe:
      operationId: onOrderCancelled
      message:
        messageId: orderCancelled
        name: OrderCancelled
        payload:
          type: object
          properties:
            orderId:
              type: string
components:
  messages:
    OrderCreated:
      messageId: orderCreated
      name: OrderCreated
      payload:
        type: object
        properties:
          orderId:
            type: string
```
