The document must declare the servers (brokers) that host its channels, so that clients know where to connect.

The root of the document must contain a `servers` object. A document without a `servers` field is reported, in both AsyncAPI 2.x and 3.x.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0 # Noncompliant {{AAR008: The AsyncAPI document must define at least one server in the 'servers' object.}}
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    subscribe:
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
channels:
  orders.created:
    subscribe:
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0 # Noncompliant {{AAR008: The AsyncAPI document must define at least one server in the 'servers' object.}}
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: broker.quality.es:9093
    protocol: kafka-secure
channels:
  orderCreated:
    address: orders.created
```
