Every channel (topic) name must follow the corporate naming convention `<cod_poaps>.<classification>.<domain>.<origin>.<scope>[.<version>]`, so that topics can be traced to their application, domain and origin.

By default the name must have five dot-separated segments, plus an optional sixth one for the version. Each segment is made of lowercase letters and digits, and several words within a segment are joined with single hyphens; uppercase letters, underscores, empty segments and leading or trailing hyphens are not allowed. In AsyncAPI 2.x the name is the channel key. In AsyncAPI 3.x it is the channel `address`, or the channel key when the channel has no `address` field; a channel whose `address` is `null` is not checked.

Parameters
----------

- `pattern` — regular expression the channel name must match, written plainly (for example `^[a-z0-9-]+(\.[a-z0-9-]+){4}$`). An empty value falls back to the default. Default: `^[a-z0-9]+(?:-[a-z0-9]+)*(?:\.[a-z0-9]+(?:-[a-z0-9]+)*){4}(?:\.[a-z0-9]+(?:-[a-z0-9]+)*)?$`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud_beca.beca: # Noncompliant {{AAR053: Channel name 'beca.cmd.alumnos.solicitud_beca.beca' does not follow the corporate naming convention '<cod_poaps>.<classification>.<domain>.<origin>.<scope>[.<version>]' (lowercase alphanumeric segments separated by dots, hyphen-joined words within a segment, no underscores).}}
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
  beca.cdc.alumnos.direccion: # Noncompliant {{AAR053: Channel name 'beca.cdc.alumnos.direccion' does not follow the corporate naming convention '<cod_poaps>.<classification>.<domain>.<origin>.<scope>[.<version>]' (lowercase alphanumeric segments separated by dots, hyphen-joined words within a segment, no underscores).}}
    subscribe:
      operationId: onAddressChanged
      message:
        name: AddressChanged
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud-beca.beca:
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
  beca.cdc.alumnos.direccion.beca.v1:
    subscribe:
      operationId: onAddressChanged
      message:
        name: AddressChanged
        payload:
          type: object
```
