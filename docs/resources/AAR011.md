The API must state the license under which it is offered.

The `info` object must contain a `license` field. A document whose `info` object has no `license` is reported, in both AsyncAPI 2.x and 3.x.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info: # Noncompliant {{AAR011: The 'info' object must contain a 'license' field.}}
  title: Orders Events
  version: 1.0.0
channels: {}
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
  license:
    name: Apache 2.0
    url: https://www.apache.org/licenses/LICENSE-2.0
channels: {}
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info: # Noncompliant {{AAR011: The 'info' object must contain a 'license' field.}}
  title: Orders Events
  version: 1.0.0
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
  license:
    name: Apache 2.0
    url: https://www.apache.org/licenses/LICENSE-2.0
```
