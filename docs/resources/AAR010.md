Every tag must explain what it groups through a `description`.

In AsyncAPI 2 the rule checks the tags of the root `tags` list and the tags of every `publish` and `subscribe` operation in `channels`. In AsyncAPI 3 it checks the tags of every operation in the root `operations` object. A tag whose `description` is missing or empty is reported.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
tags:
  - name: orders # Noncompliant {{AAR010: Tag '[object Object]' should have a 'description' field.}}
channels:
  orders.created:
    publish:
      operationId: publishOrderCreated
      tags:
        - name: orders
          description: "" # Noncompliant {{AAR010: Tag '' should have a 'description' field.}}
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
tags:
  - name: orders
    description: Events about the lifecycle of customer orders.
channels:
  orders.created:
    publish:
      operationId: publishOrderCreated
      tags:
        - name: orders
          description: Events about the lifecycle of customer orders.
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated:
    action: send
    channel:
      $ref: '#/channels/orderCreated'
    tags:
      - name: orders # Noncompliant {{AAR010: Tag '[object Object]' should have a 'description' field.}}
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated:
    action: send
    channel:
      $ref: '#/channels/orderCreated'
    tags:
      - name: orders
        description: Events about the lifecycle of customer orders.
```
