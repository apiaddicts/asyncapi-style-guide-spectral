Every tag must be documented, so each Tag object must declare a non-empty `name` and `description`.

The rule checks every Tag object in the document. In AsyncAPI 2.x these are the root `tags` and the tags of servers, `publish` and `subscribe` operations, messages (including each `oneOf` alternative), operation traits and message traits, both inline and in `components`. In AsyncAPI 3.x they are `info.tags` and the tags of servers, channels, operations, messages, operation traits and message traits, both inline and in `components`, plus the entries of `components.tags`; a tag given as a `$ref` is checked once, at its definition.

A missing `name` or `description`, a field that is empty (`null`, or a string made only of whitespace), or a tag that is not an object is a violation.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
tags:
  - name: orders # Noncompliant {{AAR076: Tag 'orders' must declare 'description'.}}
channels:
  orders.placed:
    publish:
      tags:
        - name: order-events
          description: '' # Noncompliant {{AAR076: The 'description' of tag 'order-events' must not be empty.}}
      message:
        messageId: orderPlaced
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
tags:
  - name: orders
    description: Events of the order lifecycle.
channels:
  orders.placed:
    publish:
      tags:
        - name: order-events
          description: Events emitted when an order changes state.
      message:
        messageId: orderPlaced
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
  tags:
    - $ref: '#/components/tags/orders'
channels:
  ordersPlaced:
    address: orders.placed
    tags:
      - description: Events emitted when an order is placed. # Noncompliant {{AAR076: The tag must declare 'name'.}}
components:
  tags:
    orders: # Noncompliant {{AAR076: Tag 'orders' must declare 'description'.}}
      name: orders
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
  tags:
    - $ref: '#/components/tags/orders'
channels:
  ordersPlaced:
    address: orders.placed
    tags:
      - name: order-placed
        description: Events emitted when an order is placed.
components:
  tags:
    orders:
      name: orders
      description: Events of the order lifecycle.
```
