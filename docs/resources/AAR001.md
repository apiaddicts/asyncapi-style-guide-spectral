Every server must use a secure protocol, so that messages travel encrypted between clients and brokers.

The `protocol` of each server in the root `servers` object must be one of `https`, `wss`, `amqps`, `kafka-secure` or `secure-mqtt`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9092
    protocol: kafka # Noncompliant {{AAR001: Server must use a secure protocol (https, wss, amqps, etc). Found 'kafka'.}}
channels: {}
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
channels: {}
```
