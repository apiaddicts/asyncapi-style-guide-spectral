The AsyncAPI version of the document must be one of the versions allowed by the organization.

The rule compares the root `asyncapi` field, with surrounding spaces trimmed, against the configured list of allowed versions. By default the allowed versions are `2.6.0`, `3.0.0` and `3.1.0`. A version that is not exactly one of them, such as an older release or an incomplete version like `3.0`, is a violation. A missing or empty `asyncapi` field is not checked.

Parameters
----------

- `allowedVersions` (default `2.6.0,3.0.0,3.1.0`): comma-separated list of the allowed values of the root `asyncapi` field. Entries are trimmed, empty entries are dropped, and each value must match an entry exactly.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.4.0 # Noncompliant {{AAR063: The asyncapi version must be one of the versions allowed by the organization}}
info:
  title: Orders Events
  version: 1.0.0
channels: {}
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels: {}
```
