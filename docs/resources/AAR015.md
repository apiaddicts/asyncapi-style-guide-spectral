The API must tell its consumers who to contact about it.

The `info` object must contain a `contact` field. A document whose `info` object has no `contact` is reported, in both AsyncAPI 2.x and 3.x.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info: # Noncompliant {{AAR015: The 'info' object must contain a 'contact' section.}}
  title: Orders Events
  version: 1.0.0
channels: {}
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
  contact:
    name: Orders Team
    url: https://quality.es/teams/orders
    email: orders-team@quality.es
channels: {}
```
