At least one channel must be documented as an error topic, so that the topics used by Spring to route failed messages are part of the contract.

An error topic name follows the pattern `<topicOriginal>.[<consumerGroup>.]error.<n>`: the original topic name, the consumer group when there is more than one consumer, then `error` and a number, for example `beca.cmd.alumnos.solicitud.beca.grupo1.error.1`. Segments are made of lowercase letters and digits, with hyphens joining words. In AsyncAPI 2.x the channel key is checked; in AsyncAPI 3.x the channel `address` is checked, and channels without an address do not count. When no channel matches, a single issue is reported on `channels`, or on the document when it has no channels.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels: # Noncompliant {{AAR057: No channel is documented as an error topic. At least one channel must follow the pattern '<topicOriginal>.[<consumerGroup>.]error.<n>' (e.g. 'beca.cmd.alumnos.solicitud.beca.grupo1.error.1') required by Spring.}}
  beca.cmd.alumnos.solicitud.beca:
    subscribe:
      operationId: onScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
  beca.cmd.alumnos.solicitud.beca.dlq:
    publish:
      operationId: publishScholarshipRequestFailed
      message:
        name: ScholarshipRequestFailed
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud.beca:
    subscribe:
      operationId: onScholarshipRequested
      message:
        name: ScholarshipRequested
        payload:
          type: object
  beca.cmd.alumnos.solicitud.beca.error.1:
    publish:
      operationId: publishScholarshipRequestFailed
      message:
        name: ScholarshipRequestFailed
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels: # Noncompliant {{AAR057: No channel is documented as an error topic. At least one channel must follow the pattern '<topicOriginal>.[<consumerGroup>.]error.<n>' (e.g. 'beca.cmd.alumnos.solicitud.beca.grupo1.error.1') required by Spring.}}
  scholarshipRequested:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      scholarshipRequested:

          type: object

    address: beca.cmd.alumnos.solicitud.beca.grupo1.error
    messages:
      scholarshipRequestFailed:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml

info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  scholarshipRequested:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      scholarshipRequested:
        payload:
          type: object
  scholarshipRequestFailed:
    address: beca.cmd.alumnos.solicitud.beca.grupo1.error.1
    messages:
      scholarshipRequestFailed:
        payload:
          type: object
```
