Avro payloads must declare the standard Avro schema format, so that every tool reading the document resolves the same Avro version.

Every `schemaFormat` value that refers to Avro (it contains `application/vnd.apache.avro`, in any letter case) must be exactly `application/vnd.apache.avro;version=1.9.0`. Any other version, letter case, spacing, suffix such as `+json` or extra parameter is reported. Non-Avro formats are not checked. In AsyncAPI 2.x `schemaFormat` is declared on the message; in AsyncAPI 3.x it is declared on the multi-format schema object, such as a message `payload`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud.beca:
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        schemaFormat: application/vnd.apache.avro;version=1.11.1 # Noncompliant {{AAR056: The 'schemaFormat' value 'application/vnd.apache.avro;version=1.11.1' must be exactly 'application/vnd.apache.avro;version=1.9.0' when the payload uses Avro.}}
        payload:
          type: record
          name: ScholarshipRequested
          namespace: org.madrid.beca.cmd.alumnos
          fields:
            - name: studentId
              type: string
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  beca.cmd.alumnos.solicitud.beca:
    publish:
      operationId: publishScholarshipRequested
      message:
        name: ScholarshipRequested
        schemaFormat: application/vnd.apache.avro;version=1.9.0
        payload:
          type: record
          name: ScholarshipRequested
          namespace: org.madrid.beca.cmd.alumnos
          fields:
            - name: studentId
              type: string
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  scholarshipRequested:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      scholarshipRequested:
        payload:
          schemaFormat: application/vnd.apache.avro+json;version=1.9.0 # Noncompliant {{AAR056: The 'schemaFormat' value 'application/vnd.apache.avro+json;version=1.9.0' must be exactly 'application/vnd.apache.avro;version=1.9.0' when the payload uses Avro.}}
          schema:
            type: record
            name: ScholarshipRequested
            namespace: org.madrid.beca.cmd.alumnos
            fields:
              - name: studentId
                type: string
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Scholarship Requests
  version: 1.0.0
channels:
  scholarshipRequested:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      scholarshipRequested:
        payload:
          schemaFormat: application/vnd.apache.avro;version=1.9.0
          schema:
            type: record
            name: ScholarshipRequested
            namespace: org.madrid.beca.cmd.alumnos
            fields:
              - name: studentId
                type: string
```
