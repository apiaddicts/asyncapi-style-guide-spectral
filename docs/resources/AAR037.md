Every binding must declare its `bindingVersion`, so that tools know which version of the binding definition applies.

The rule checks each binding in the `bindings` of every server in `servers` and of every channel in `channels`; in AsyncAPI 2 also of the `publish` and `subscribe` operations of each channel and of their `message`. A message given as a `$ref` is reported where it is defined. A binding whose `bindingVersion` is missing or empty is reported.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
    bindings:
      kafka: # Noncompliant {{AAR037: Binding 'kafka' must specify a 'bindingVersion' field.}}
        schemaRegistryUrl: https://registry.quality.es
channels:
  orders.created:
    publish:
      bindings:
        kafka: # Noncompliant {{AAR037: Binding 'kafka' must specify a 'bindingVersion' field.}}
          groupId:
            type: string
            enum:
              - orders-service
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
    bindings:
      kafka:
        schemaRegistryUrl: https://registry.quality.es
        bindingVersion: 0.4.0
channels:
  orders.created:
    publish:
      bindings:
        kafka:
          groupId:
            type: string
            enum:
              - orders-service
          bindingVersion: 0.4.0
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: broker.quality.es:9093
    protocol: kafka-secure
    bindings:
      kafka:
        schemaRegistryUrl: https://registry.quality.es
        bindingVersion: "" # Noncompliant {{AAR037: Binding 'kafka' must specify a 'bindingVersion' field.}}
channels:
  orderCreated:
    address: orders.created
    bindings:
      kafka: # Noncompliant {{AAR037: Binding 'kafka' must specify a 'bindingVersion' field.}}
        partitions: 3
        replicas: 3
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: broker.quality.es:9093
    protocol: kafka-secure
    bindings:
      kafka:
        schemaRegistryUrl: https://registry.quality.es
        bindingVersion: 0.5.0
channels:
  orderCreated:
    address: orders.created
    bindings:
      kafka:
        partitions: 3
        replicas: 3
        bindingVersion: 0.5.0
```
