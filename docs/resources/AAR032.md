Numeric properties should restrict the values they accept, so that producers and consumers agree on their range.

The rule checks the properties, at any depth, of the schemas in `components.schemas`, of the `payload` of the messages in `components.messages` and of the `payload` of the messages written in the channels (in AsyncAPI 2 the `message` of each `publish` and `subscribe` operation, in AsyncAPI 3 each entry of the channel `messages`). References are not followed.

A property whose `type` is `integer` or `number` is reported when it declares none of `minimum`, `exclusiveMinimum`, `maximum`, `exclusiveMaximum`, `format`, a non-empty `enum` or `const`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      message:
        contentType: application/json
        payload:
          type: object
          properties:
            quantity: # Noncompliant {{AAR032: Numeric property of type 'integer' should have at least one of: minimum, maximum, format, enum, or const restriction.}}
              type: integer
components:
  schemas:
    OrderLine:
      type: object
      properties:
        price: # Noncompliant {{AAR032: Numeric property of type 'number' should have at least one of: minimum, maximum, format, enum, or const restriction.}}
          type: number
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      message:
        contentType: application/json
        payload:
          type: object
          properties:
            quantity:
              type: integer
              minimum: 1
              maximum: 999
components:
  schemas:
    OrderLine:
      type: object
      properties:
        price:
          type: number
          format: double
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        $ref: '#/components/messages/OrderCreated'
components:
  messages:
    OrderCreated:
      contentType: application/json
      payload:
        type: object
        properties:
          lines:
            type: array
            items:
              type: object
              properties:
                quantity: # Noncompliant {{AAR032: Numeric property of type 'integer' should have at least one of: minimum, maximum, format, enum, or const restriction.}}
                  type: integer
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        $ref: '#/components/messages/OrderCreated'
components:
  messages:
    OrderCreated:
      contentType: application/json
      payload:
        type: object
        properties:
          lines:
            type: array
            items:
              type: object
              properties:
                quantity:
                  type: integer
                  format: int32
                  minimum: 1
```
