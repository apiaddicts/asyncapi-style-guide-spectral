Every server must state where it is and how to talk to it, so that clients can connect without guessing.

The rule checks every server of the root `servers` object and of `components.servers`. In AsyncAPI 2.x a server must declare `url`, `protocol` and `protocolVersion`; in AsyncAPI 3.x it must declare `host`, `protocol` and `protocolVersion`. A missing field is reported on the server name, and a field that is empty (a blank string, `null`, an empty object or an empty list) is reported on the field itself. A server that is not an object is reported too.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production: # Noncompliant {{AAR086: Server 'production' must declare 'protocolVersion'.}}
    url: broker.quality.es:9093
    protocol: kafka-secure
  staging:
    url: '' # Noncompliant {{AAR086: The 'url' of server 'staging' must not be empty.}}
    protocol: kafka-secure
    protocolVersion: 3.3.0
channels: {}
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
    protocolVersion: 3.3.0
  staging:
    url: broker-pre.quality.es:9093
    protocol: kafka-secure
    protocolVersion: 3.3.0
channels: {}
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production: # Noncompliant {{AAR086: Server 'production' must declare 'host'.}} {{AAR086: Server 'production' must declare 'protocolVersion'.}}
    protocol: kafka-secure
components:
  servers:
    backup:
      host: backup.quality.es:9093
      protocol: # Noncompliant {{AAR086: The 'protocol' of server 'backup' must not be empty.}}
      protocolVersion: 3.3.0
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: broker.quality.es:9093
    protocol: kafka-secure
    protocolVersion: 3.3.0
components:
  servers:
    backup:
      host: backup.quality.es:9093
      protocol: kafka-secure
      protocolVersion: 3.3.0
```
