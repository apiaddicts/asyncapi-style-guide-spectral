The `name` of every Avro record must be written in CamelCase with an uppercase first letter (e.g. `SolicitudComunicacion`, `ResultadoComunicacionMail`).

The rule checks every object with `type: record` anywhere in the document: Avro message payloads (the `payload` in AsyncAPI 2.x, `payload.schema` in AsyncAPI 3.x), schemas under `components`, and the records nested inside `fields[].type`, unions, array `items` and map `values`. A record without a `name` is not checked.

A name complies when it starts with an uppercase letter followed by at least one lowercase letter or digit, and every further word starts with an uppercase letter. Underscores, hyphens, dots, a lowercase or numeric first character, a single letter, a fully uppercase name or a leading acronym (e.g. `XMLOrder`) are violations.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.evt.order.created:
    subscribe:
      operationId: receiveOrderCreated
      message:
        schemaFormat: application/vnd.apache.avro;version=1.9.0
        payload:
          type: record
          name: order_created # Noncompliant {{AAR059: Avro record name 'order_created' must be in CamelCase with an uppercase first letter (e.g. SolicitudComunicacion, ResultadoComunicacionMail).}}
          namespace: es.quality.orders
          fields:
            - name: orderId
              type: string
            - name: shippingAddress
              type:
                type: record
                name: shippingAddress # Noncompliant {{AAR059: Avro record name 'shippingAddress' must be in CamelCase with an uppercase first letter (e.g. SolicitudComunicacion, ResultadoComunicacionMail).}}
                fields:
                  - name: city
                    type: string
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.evt.order.created:
    subscribe:
      operationId: receiveOrderCreated
      message:
        schemaFormat: application/vnd.apache.avro;version=1.9.0
        payload:
          type: record
          name: OrderCreated
          namespace: es.quality.orders
          fields:
            - name: orderId
              type: string
            - name: shippingAddress
              type:
                type: record
                name: ShippingAddress
                fields:
                  - name: city
                    type: string
```

            type: record
            name: OrderCreated

              - name: lines

                  type: array

                    type: record
                    name: order-line # Noncompliant {{AAR059: Avro record name 'order-line' must be in CamelCase with an uppercase first letter (e.g. SolicitudComunicacion, ResultadoComunicacionMail).}}

                  - 'null'
