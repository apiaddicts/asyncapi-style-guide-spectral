Every channel must declare its Kafka binding, so that the topic configuration behind each channel is documented.

The rule checks every channel of the root `channels` object and of `components.channels`, in AsyncAPI 2.x and 3.x alike. The channel must declare `bindings` with a `kafka` entry whose value is an object; any object is accepted, an empty `{}` included. A channel without `bindings` is reported on its name, `bindings` without a `kafka` entry is reported on the `bindings` field, and a `kafka` entry that is not an object (for example an empty value) is reported on that entry.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created: # Noncompliant {{AAR090: Channel 'orders.created' must declare a 'kafka' binding.}}
    subscribe:
      message:
        payload:
          type: object
  orders.cancelled:
    bindings: # Noncompliant {{AAR090: Channel 'orders.cancelled' must declare a 'kafka' binding.}}
      amqp:
        is: routingKey
    subscribe:
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    bindings:
      kafka:
        topic: orders.created
        partitions: 3
        replicas: 3
        bindingVersion: 0.4.0
    subscribe:
      message:
        payload:
          type: object
  orders.cancelled:
    bindings:
      kafka: {}
    subscribe:
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated: # Noncompliant {{AAR090: Channel 'orderCreated' must declare a 'kafka' binding.}}
    address: orders.created
  orderCancelled:
    address: orders.cancelled
    bindings:
      kafka: # Noncompliant {{AAR090: The 'kafka' binding of channel 'orderCancelled' must be an object.}}
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    bindings:
      kafka:
        topic: orders.created
        partitions: 3
        replicas: 3
        bindingVersion: 0.5.0
  orderCancelled:
    address: orders.cancelled
    bindings:
      kafka: {}
```
