Every server must point to a host of the enterprise domain, so that clients only connect to the organization's own brokers.

The rule checks every server of the root `servers` object and of `components.servers`. The host is read from the `url` in AsyncAPI 2.x and from the `host` in 3.x, without scheme, user info, port or path; when the field lists several hosts separated by commas, each one is checked. A `{variable}` placeholder is replaced by every value the server variable can take (its `enum` values and its `default`), and every resulting host must match; a placeholder whose variable provides neither is checked as written.

A host that does not match the configured regular expression is reported. By default only `quality.es` and its first-level subdomains, such as `broker.quality.es`, are accepted.

Parameters
----------

- `pattern` — regular expression every server host must match. It is written plainly (`^([a-zA-Z0-9-]+\.)?quality\.es$`) or as a `/source/flags` literal (`/^broker[0-9]*\.quality\.es$/i`). An empty or invalid value falls back to the default. Default: `^([a-zA-Z0-9-]+\.)?quality\.es$`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: kafka-secure://eu.broker.quality.es:9093 # Noncompliant {{AAR083: Server 'production' host 'eu.broker.quality.es' must match '^([a-zA-Z0-9-]+\.)?quality\.es$'.}}
    protocol: kafka-secure
  partner:
    url: broker.partner.net:9093 # Noncompliant {{AAR083: Server 'partner' host 'broker.partner.net' must match '^([a-zA-Z0-9-]+\.)?quality\.es$'.}}
    protocol: kafka-secure
channels: {}
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: kafka-secure://broker.quality.es:9093
    protocol: kafka-secure
  partner:
    url: partners.quality.es:9093
    protocol: kafka-secure
channels: {}
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: 'kafka.{domain}:9093' # Noncompliant {{AAR083: Server 'production' host 'kafka.partner.net' must match '^([a-zA-Z0-9-]+\.)?quality\.es$'.}}
    protocol: kafka-secure
    variables:
      domain:
        enum:
          - quality.es
          - partner.net
        default: quality.es
components:
  servers:
    backup:
      host: broker.backup.net:9093 # Noncompliant {{AAR083: Server 'backup' host 'broker.backup.net' must match '^([a-zA-Z0-9-]+\.)?quality\.es$'.}}
      protocol: kafka-secure
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: '{cluster}.quality.es:9093'
    protocol: kafka-secure
    variables:
      cluster:
        enum:
          - broker
          - broker-eu
        default: broker
components:
  servers:
    backup:
      host: backup.quality.es:9093
      protocol: kafka-secure
```
