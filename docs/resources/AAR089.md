Every security mechanism applied to the API must be one the organization approves, so that clients only authenticate with strong mechanisms.

The rule checks the `security` of every server (root `servers` and `components.servers`), of every operation and of every operation trait, including those under `components`. In AsyncAPI 2.x each security requirement names schemes of `components.securitySchemes`, and every scheme of every requirement is checked where the requirement names it. In AsyncAPI 3.x each `security` item is a security scheme: a referenced scheme is reported on the item, and an inline scheme on its `type`.

A scheme whose `type` is not in the configured list of approved types is reported, as is a `type` that is not a string. Every alternative of a `security` list must be approved, and security schemes that nothing applies are not checked. By default only `scramSha512` and `X509` are approved.

Parameters
----------

- `allowed-security-types` — comma-separated list of the approved security scheme types, written as the AsyncAPI `type` values (`userPassword`, `apiKey`, `X509`, `symmetricEncryption`, `asymmetricEncryption`, `httpApiKey`, `http`, `oauth2`, `openIdConnect`, `plain`, `scramSha256`, `scramSha512`, `gssapi`). Entries are trimmed and compared exactly, case included. An empty value falls back to the default. Default: `scramSha512,X509`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
    security:
      - saslPlain: [] # Noncompliant {{AAR089: Security scheme 'saslPlain' type 'plain' must be an approved mechanism: 'scramSha512', 'X509'.}}
channels:
  orders.created:
    publish:
      security:
        - saslScram256: [] # Noncompliant {{AAR089: Security scheme 'saslScram256' type 'scramSha256' must be an approved mechanism: 'scramSha512', 'X509'.}}
      message:
        payload:
          type: object
components:
  securitySchemes:
    saslPlain:
      type: plain
    saslScram256:
      type: scramSha256
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
    security:
      - saslScram512: []
      - mtls: []
channels:
  orders.created:
    publish:
      security:
        - saslScram512: []
      message:
        payload:
          type: object
components:
  securitySchemes:
    saslScram512:
      type: scramSha512
    mtls:
      type: X509
```
