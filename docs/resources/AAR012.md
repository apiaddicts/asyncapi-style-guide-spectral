Every operation must declare an `operationId`, so that tools and code generators can refer to it unambiguously.

In AsyncAPI 2 the rule checks the `publish` and `subscribe` operations of every channel in `channels`. In AsyncAPI 3 it checks every operation in the root `operations` object, which must carry an `operationId` field in addition to its key. An operation whose `operationId` is missing or empty is reported.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish: # Noncompliant {{AAR012: Operation must declare an 'operationId'.}}
      summary: Publish an event when an order is created.
      message:
        payload:
          type: object
  orders.cancelled:
    subscribe:
      operationId: "" # Noncompliant {{AAR012: Operation must declare an 'operationId'.}}
      summary: Consume the events of cancelled orders.
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      operationId: publishOrderCreated
      summary: Publish an event when an order is created.
      message:
        payload:
          type: object
  orders.cancelled:
    subscribe:
      operationId: consumeOrderCancelled
      summary: Consume the events of cancelled orders.
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated: # Noncompliant {{AAR012: Operation must declare an 'operationId'.}}
    action: send
    channel:
      $ref: '#/channels/orderCreated'
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated:
    operationId: publishOrderCreated
    action: send
    channel:
      $ref: '#/channels/orderCreated'
```
