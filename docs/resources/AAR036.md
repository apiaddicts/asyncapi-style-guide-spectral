Descriptions must be written as sentences: they begin with a capital letter and end with a period.

The rule checks the `description` of `info`, of every channel in `channels`, of every schema in `components.schemas` and of every message in `components.messages`; in AsyncAPI 2 also of the `publish` and `subscribe` operations of each channel and of every tag in the root `tags`. Leading and trailing spaces are ignored. A description whose first character is not an uppercase letter from A to Z is reported, and so is a description whose last character is not a period; both findings can be raised on the same description. Missing or empty descriptions are not reported.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
  description: Events of the order lifecycle # Noncompliant {{AAR036: Description must end with a period. Found: "...Events of the order lifecycle"}}
channels:
  orders.created:
    description: orders placed by customers. # Noncompliant {{AAR036: Description must begin with a capital letter. Found: "orders placed by customers...."}}
    publish:
      operationId: publishOrderCreated
      description: publishes the paid order # Noncompliant {{AAR036: Description must begin with a capital letter. Found: "publishes the paid order..."}} {{AAR036: Description must end with a period. Found: "...publishes the paid order"}}
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
  description: Events of the order lifecycle.
channels:
  orders.created:
    description: Orders placed by customers.
    publish:
      operationId: publishOrderCreated
      description: Publishes the paid order.
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
  description: Events of the order lifecycle.
channels:
  orderCreated:
    address: orders.created
    description: orders placed by customers. # Noncompliant {{AAR036: Description must begin with a capital letter. Found: "orders placed by customers...."}}
    messages:
      orderCreated:
        $ref: '#/components/messages/OrderCreated'
components:
  messages:
    OrderCreated:
      description: Order with lines and totals # Noncompliant {{AAR036: Description must end with a period. Found: "...Order with lines and totals"}}
      payload:
        type: object
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
  description: Events of the order lifecycle.
channels:
  orderCreated:
    address: orders.created
    description: Orders placed by customers.
    messages:
      orderCreated:
        $ref: '#/components/messages/OrderCreated'
components:
  messages:
    OrderCreated:
      description: Order with lines and totals.
      payload:
        type: object
```
