String properties should restrict the values they accept, so that producers and consumers agree on their length or shape.

The rule checks the properties, at any depth, of the schemas in `components.schemas`, of the `payload` of the messages in `components.messages` and of the `payload` of the messages written in the channels (in AsyncAPI 2 the `message` of each `publish` and `subscribe` operation, in AsyncAPI 3 each entry of the channel `messages`). References are not followed.

A property whose `type` is `string` is reported when it declares none of `minLength`, `maxLength`, `pattern`, a non-empty `enum`, `const` or `format`.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      message:
        contentType: application/json
        payload:
          type: object
          properties:
            orderId: # Noncompliant {{AAR033: String property should have at least one of: minLength, maxLength, pattern, enum, const, or format restriction.}}
              type: string
components:
  schemas:
    Customer:
      type: object
      properties:
        name: # Noncompliant {{AAR033: String property should have at least one of: minLength, maxLength, pattern, enum, const, or format restriction.}}
          type: string
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      message:
        contentType: application/json
        payload:
          type: object
          properties:
            orderId:
              type: string
              pattern: '^ORD-[0-9]{4,10}$'
components:
  schemas:
    Customer:
      type: object
      properties:
        name:
          type: string
          minLength: 1
          maxLength: 120
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        contentType: application/json
        payload:
          type: object
          properties:
            status: # Noncompliant {{AAR033: String property should have at least one of: minLength, maxLength, pattern, enum, const, or format restriction.}}
              type: string
            customer:
              type: object
              properties:
                email: # Noncompliant {{AAR033: String property should have at least one of: minLength, maxLength, pattern, enum, const, or format restriction.}}
                  type: string
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        contentType: application/json
        payload:
          type: object
          properties:
            status:
              type: string
              enum:
                - CREATED
                - PAID
            customer:
              type: object
              properties:
                email:
                  type: string
                  format: email
```
