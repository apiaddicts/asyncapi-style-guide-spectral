Every operation must be tagged, so that operations can be grouped and filtered in documentation and catalogs.

In AsyncAPI 2 the rule checks the `publish` and `subscribe` operations of every channel in `channels`. In AsyncAPI 3 it checks every operation in the root `operations` object. An operation without a `tags` field is reported.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish: # Noncompliant {{AAR009: Operation must declare at least one tag.}}
      operationId: publishOrderCreated
      message:
        payload:
          type: object
  orders.cancelled:
    subscribe: # Noncompliant {{AAR009: Operation must declare at least one tag.}}
      operationId: consumeOrderCancelled
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      operationId: publishOrderCreated
      tags:
        - name: orders
      message:
        payload:
          type: object
  orders.cancelled:
    subscribe:
      operationId: consumeOrderCancelled
      tags:
        - name: orders
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated: # Noncompliant {{AAR009: Operation must declare at least one tag.}}
    action: send
    channel:
      $ref: '#/channels/orderCreated'
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated:
    action: send
    channel:
      $ref: '#/channels/orderCreated'
    tags:
      - name: orders
```
