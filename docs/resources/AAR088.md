Every channel must state on which servers it is available, so that producers and consumers know which broker carries each topic.

The rule checks every channel of the root `channels` object and of `components.channels`. The channel must declare `servers`, and the list must contain at least one entry that points to a server of the root `servers` object: in AsyncAPI 2.x an entry is a server name, in 3.x a reference such as `$ref: '#/servers/production'`. A channel without `servers` is reported on its name; a `servers` list that is empty or does not point to any root server (for example one that only references `components.servers`) is reported on the `servers` field.

AsyncAPI documents older than 2.2.0, whose channels cannot declare servers, are not checked.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
channels:
  orders.created: # Noncompliant {{AAR088: Channel 'orders.created' must declare 'servers'.}}
    subscribe:
      message:
        payload:
          type: object
  orders.cancelled:
    servers: # Noncompliant {{AAR088: The 'servers' of channel 'orders.cancelled' must list at least one server defined in the root 'servers' object.}}
      - staging
    subscribe:
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    url: broker.quality.es:9093
    protocol: kafka-secure
channels:
  orders.created:
    servers:
      - production
    subscribe:
      message:
        payload:
          type: object
  orders.cancelled:
    servers:
      - production
    subscribe:
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: broker.quality.es:9093
    protocol: kafka-secure
channels:
  orderCreated: # Noncompliant {{AAR088: Channel 'orderCreated' must declare 'servers'.}}
    address: orders.created
  orderCancelled:
    address: orders.cancelled
    servers: # Noncompliant {{AAR088: The 'servers' of channel 'orderCancelled' must list at least one server defined in the root 'servers' object.}}
      - $ref: '#/components/servers/backup'
components:
  servers:
    backup:
      host: backup.quality.es:9093
      protocol: kafka-secure
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
servers:
  production:
    host: broker.quality.es:9093
    protocol: kafka-secure
channels:
  orderCreated:
    address: orders.created
    servers:
      - $ref: '#/servers/production'
  orderCancelled:
    address: orders.cancelled
    servers:
      - $ref: '#/servers/production'
```
