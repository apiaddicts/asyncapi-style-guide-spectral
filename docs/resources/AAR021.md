Every operation must have a short `summary` of what it does.

In AsyncAPI 2 the rule checks the `publish` and `subscribe` operations of every channel in `channels`. In AsyncAPI 3 it checks every operation in the root `operations` object. An operation whose `summary` is missing or empty is reported.

Noncompliant Code Example (AsyncAPI 2)
--------------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish: # Noncompliant {{AAR021: Operation must have a 'summary' field.}}
      operationId: publishOrderCreated
      message:
        payload:
          type: object
  orders.cancelled:
    subscribe:
      operationId: consumeOrderCancelled
      summary: "" # Noncompliant {{AAR021: Operation must have a 'summary' field.}}
      message:
        payload:
          type: object
```

Compliant Solution (AsyncAPI 2)
-------------------------------

```yaml
asyncapi: 2.6.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orders.created:
    publish:
      operationId: publishOrderCreated
      summary: Publish an event when an order is created.
      message:
        payload:
          type: object
  orders.cancelled:
    subscribe:
      operationId: consumeOrderCancelled
      summary: Consume the events of cancelled orders.
      message:
        payload:
          type: object
```

Noncompliant Code Example (AsyncAPI 3)
--------------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated: # Noncompliant {{AAR021: Operation must have a 'summary' field.}}
    action: send
    channel:
      $ref: '#/channels/orderCreated'
```

Compliant Solution (AsyncAPI 3)
-------------------------------

```yaml
asyncapi: 3.0.0
info:
  title: Orders Events
  version: 1.0.0
channels:
  orderCreated:
    address: orders.created
    messages:
      orderCreated:
        payload:
          type: object
operations:
  publishOrderCreated:
    action: send
    channel:
      $ref: '#/channels/orderCreated'
    summary: Publish an event when an order is created.
```
